# How to Redeem 3-Month DataCamp Subscription with GitHub Education Pack

This guide will help you redeem your 3-month free access to DataCamp through the GitHub Student Developer Pack.

## Prerequisites

Before you begin, make sure you have:

1. ✅ A GitHub account
2. ✅ A verified student status through GitHub Education
3. ✅ Access to the GitHub Student Developer Pack

## Step 1: Get GitHub Student Developer Pack

If you haven't already applied for the GitHub Student Developer Pack:

1. Go to [GitHub Education](https://education.github.com/pack)
2. Click on "Get your pack" or "Sign up for Student Developer Pack"
3. Fill out the application form with:
   - Your academic email address (if available)
   - Proof of student status (student ID, transcript, or enrollment letter)
   - Information about how you plan to use GitHub
4. Wait for verification (usually takes a few hours to a few days)

## Step 2: Access the DataCamp Offer

Once your GitHub Student Developer Pack is approved:

1. Visit the [GitHub Student Developer Pack benefits page](https://education.github.com/pack/offers)
2. Scroll down or search for **DataCamp** in the list of offers
3. Click on the DataCamp offer card

## Step 3: Redeem Your DataCamp Subscription

1. Click the "**Get access by connecting your GitHub account**" or similar button on the DataCamp offer
2. You'll be redirected to DataCamp's website
3. You may need to:
   - Create a new DataCamp account if you don't have one
   - Or log in to your existing DataCamp account
4. Authorize the connection between GitHub and DataCamp
5. The 3-month free subscription should be automatically applied to your account

## Step 4: Verify Your Subscription

1. Log in to your [DataCamp account](https://www.datacamp.com/)
2. Go to your account settings or subscription page
3. Verify that you have access to premium content
4. You should see that your subscription is active for 3 months

## Important Notes

- ⏰ The 3-month access starts from the date of redemption
- 📚 You'll have full access to all DataCamp courses during this period
- 🔄 The subscription does not auto-renew (you won't be charged)
- 📧 You may receive an email confirmation from DataCamp
- ⚠️ Make sure to use the same email for both GitHub and DataCamp if possible

## Troubleshooting

### Issue: Can't find DataCamp in the Student Pack offers

**Solution:** Make sure your GitHub Student Developer Pack is approved. Check your email for confirmation from GitHub Education.

### Issue: Already have a DataCamp account

**Solution:** You can still redeem the offer with an existing account. Just log in when prompted during the redemption process.

### Issue: The offer says "Already redeemed"

**Solution:** Each student can only redeem the DataCamp offer once per GitHub Student Developer Pack approval period. If you've already redeemed it, you cannot redeem it again.

### Issue: Subscription not showing up

**Solution:** 
1. Log out and log back in to DataCamp
2. Check your subscription page
3. Contact DataCamp support if the issue persists
